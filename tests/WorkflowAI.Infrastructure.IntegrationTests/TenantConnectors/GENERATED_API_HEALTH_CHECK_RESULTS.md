     - Test key directly: `curl -H "Authorization: Bearer {key}" https://api.hubapi.com/crm/v3/objects/contacts`

- **Set up alerts**: Create alerts for APIs that change from working to failing

- **Implement retry logic**: Some transient 401/403 errors may succeed on retry
